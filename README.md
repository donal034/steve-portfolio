## 🛠️ Run Locally

## 🚀 Deploy on GitHub Pages

1. Go to **Settings → Pages**
2. Source : `Deploy from a branch`
3. Branch : `main` / `root` → Save
4. Your site will be live at : `https://donal034.github.io/steve-portfolio`
